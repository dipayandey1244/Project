# HYROX 75 — Personal Training OS

A lightweight personal fitness tracker built around an 88 kg → 75 kg fat-loss goal and progressive HYROX preparation.

## Features

- Day-specific strength, aerobic and HYROX sessions
- Add custom exercises and activities
- Log actual reps, distance, load, pace and notes
- Track bodyweight and HYROX rounds
- Eight-week roadmap toward full HYROX completion
- Local achievement history via browser storage
- Generate an achievement email and open the device mail app
- Responsive mobile-first UI

## Run

Open `index.html` in a browser or serve the directory with any static web server.

## Data

Workout history is stored locally in the browser. No backend or external analytics are included.
